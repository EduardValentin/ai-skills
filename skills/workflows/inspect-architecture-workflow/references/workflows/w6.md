# W6. Components, cycles, and stability

Reads: the assess output, query metrics, component-graph, cycles, volatility, groups.

Procedure:
1. Build the component graph; detect cycles.
2. For every component edge, compare stability (fan-in versus fan-out) at both ends.
3. For every recent change and the change under review, list the touched components and look up their cohesion groups with `query groups`; a component may belong to several groups. Note how much of each component its consumers use.
4. Compute D and volatility when metrics exist; compare with the previous run.
5. Check versioning and adoption across release units.

Rows marked "(assessed by the command)" come decided in the `arch assess` output, which the coordinator merges: do not re-derive or return them, and judge only the other rows and the unassessed part of a partly assessed row. In plan review, apply them to `proposed` rows yourself; the command cannot see those.

| Condition | Verdict | Rule | Base severity |
|---|---|---|---|
| Cycle in the component graph (assessed by the command) | SHOULD_CHANGE | R30 | blocker |
| Cycle among modules (assessed by the command) | SHOULD_CHANGE | R30 | blocker |
| Edge from a more stable component to a less stable one (assessed by the command) | SHOULD_CHANGE | R31 | major |
| Heavily depended-on component that is concrete and changed in the recent history (assessed by the command in a change review, as a zone-of-pain component the change touches) | SHOULD_CHANGE | R31, R32 | major |

| Change touches a component that shares no recorded cohesion group with the other touched components (the change spreads across groups) (assessed by the command) | SHOULD_CHANGE | R27 | major |
| Change touches several components that all belong to one recorded cohesion group, or touches a single component | OK | R27 |  |
| Consumer imports a component for fewer than a quarter of its exported symbols | SHOULD_CHANGE | R27 | minor |

| Component whose cohesion position and cost are not stated and whose boundaries have not been revisited while change patterns shifted | SHOULD_CHANGE | R28 | minor |

run's values.
